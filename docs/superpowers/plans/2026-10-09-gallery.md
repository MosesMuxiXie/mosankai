# MOSANKAI Gallery

Approved brief: build /gallery and /gallery/:slug, with nine verified public repositories, three featured projects, bilingual descriptions, search/filtering and an authenticated editor in the existing dashboard. Rain-window visual design without emotional slogans. No new dependencies or Vercel function.

1. Data/API: validate works and source URLs; seed nine projects; independent local/Redis storage; versioned atomic saves; public filtering; reuse site-settings function.
2. Public UI: independent HTML/CSS/JS, list/detail routing, bilingual content, keyboard/mobile support, homepage entry.
3. Admin UI: add/edit/preview/reorder/feature/hide/republish; new works hidden; image compression; preserve edits on conflict/failure.
4. Assets and verification: generated rain hero and three conceptual covers, WebP, meaningful Node integration tests, browser widths 375/768/1440, full npm test, deployment build and publication.

Verification: unauthorized reads/writes rejected; invalid URLs/images and duplicate slugs rejected; stale/concurrent saves rejected; empty catalogue preserved; stored data not replaced by seeds; hidden items absent publicly; direct routes work; existing site behavior remains intact.
