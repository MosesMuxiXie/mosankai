03 / Thinking patterns

识别题型，建立答题路径。

预测的是常见能力要求，不是具体考试命题。
常见题型看到什么 → 做什么答案必须留下的证据
变量分类 / 选图先判断数值是否有算术意义，再选分类图或定量图。个体、变量、类型；图名与单位。
双向表 / 关联圈出“在……之中”，用对应小组合计作分母。比较条件百分比；只据观察关联不能推出因果。
描述 / 比较分布SOCS：Shape、Outliers、Center、Spread。变量名、单位、数据证据；比较时用“更高 / 更分散”。
统计量 / 异常值排序 → 中位数与四分位数 → IQR → 两个围栏。严格小于或大于围栏才判异常；须端为最远非异常观测。
百分位 / 累积图从数值向上读比例；从比例向右读数值。说明低于该值的观测占比；分组图插值只是估计。
标准化 / 线性变换z = (x − 中心) / 标准差；y = a + bx。z 无单位；平移不改离散程度；缩放标准差用 |b|。
正态正向 / 反向画图 → 标准化 → 左尾、补集或相减；反求先找 z。分布参数、边界、计算过程、带情境的结论。
判断近似正态结合直方图与正态概率图观察。大致对称、单峰；概率图接近直线且无明显系统偏离。

分布比较：A 组的中位数为 __ 单位，高于 B 组的 __；A 组 IQR 为 __，说明中间 50% 的数据更分散。再比较形状与异常值。

标准分：该观测的 z = __，表示它比该组均值高 / 低 __ 个标准差。

正态概率：在给定的正态模型下，约 __% 的 [研究对象] 的 [变量] 落在 [区间与单位] 内。

考前公式卡

x̄ = Σxᵢ / n
s = √[Σ(xᵢ − x̄)² / (n − 1)]

样本标准差用 n − 1，要求 n ≥ 2；s 与原变量同单位，s² 的单位平方。

IQR = Q₃ − Q₁
围栏：Q₁ − 1.5 IQR，Q₃ + 1.5 IQR

中位数与 IQR 对极端值稳健；均值与标准差敏感。

z = (x − μ) / σ
x = μ + zσ

样本标准化用 x̄、s；标准化不自动使数据正态。

若 Y = a + bX：均值变为 a + bμ，标准差变为 |b|σ，方差变为 b²σ²。b > 0 时四分位数同样变换；b < 0 时顺序反转，左右偏态对调，Q₁(Y)=a+bQ₃(X)。b=0 时全部成为常数，无法再除以标准差标准化。

本手册沿用课件 N(μ, σ) 的记法：第二个参数是标准差。部分教材采用 N(μ, σ²)，读题时务必核对。

05 / A 90-minute review

00–15 min / 找薄弱点
