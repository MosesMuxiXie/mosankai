MCP CONNECTION

Use findatime with an MCP client

Add findatime to an assistant that supports remote Streamable HTTP MCP. The assistant can then use the scheduling tools below.

Remote MCP address · Streamable HTTP https://mosankai.com/api/mcp
✓Authentication: none required.

How to connect

  1. In your client's MCP settings, add a remote server using Streamable HTTP.
  2. Paste the address above and choose no authentication.
  3. Once connected, ask your assistant to create or check a meeting. Include the date, time, and time zone.

Try saying

“Create a 60-minute project meeting in Asia/Shanghai next Saturday, with options at 14:00 and 16:00. Give me the share link.”

“Read this meeting link and its responses. I can attend the first option; submit my availability.”

Available tools

  • findatime_create_meetingSet a title, your name, a 30–480 minute duration in 30-minute steps, a time zone, and 1–10 candidate times. Get a share link and a private creator token.
  • findatime_get_meetingUse a known meeting ID to read candidate times, votes, and participants. This does not list every meeting.
  • findatime_submit_availabilityRead candidate time IDs, then submit your choices or mark yourself unavailable. No token is needed the first time; use your returned participantToken or creatorToken to update your response.

Share only the meeting link. creatorToken and participantToken can change your response: keep them in a trusted client. A name cannot recover a lost token.
